# RoweMod 0.5.5

Updates now clean up after themselves. After a successful install, completed installation copies and updater-owned downloaded/extracted packages are removed. The two newest successful recovery backups are kept per game installation. Failed backups, newer pending updates, unknown folders, settings, saves and other mods are preserved.

Repeated launches reuse a verified pending update instead of downloading it again. Damaged or modified cached packages are rejected and downloaded afresh.

Cleanup stays inside RoweMod's local cache directories, skips active downloads and refuses junctions or linked trees. Manually extracted folders and ZIPs in Downloads are left to the user. Older unmarked download caches are preserved; successful old installation copies are matched to backup receipts.

Validation covers retention, completed staging/cache removal, active-download protection, future updates, failed backups, other installations, unknown folders, junction safety, installer rollback, cached-package integrity and the full deferred update flow. This release makes no new claim about the unresolved live host-visibility test.

Close the game and RoweMod Online to let an automatic update finish, or extract **RoweMod-0.5.5.zip** and run **install.cmd**.
