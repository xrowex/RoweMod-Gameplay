# RoweMod 0.5.3

Multiplayer now has separate **Join** and **Host** views with spaced sections and
full-width actions. Code entry and session details are tucked away until needed.
The active-session view shows players, park and Leave Session.

Opening Multiplayer starts Steam and searches for friends automatically. Host or
join requests made during startup finish when Steam is ready, even if the menu
is closed. The visible browser refreshes periodically.

Joining automatically loads the host's stock park. Further host park changes are
followed too. Loading uses verified package paths, ignores repeated load requests,
and waits for the destination and player spawn before acknowledging arrival and
resuming skater sync. Timeout/failure status includes a retry action.

Automatic loading supports **Outdoor Skatepark, The Big Hall and Observatory**.
Custom maps and clothing assets are not downloaded. Both players should update.

Validation: 17 Lua suites and 43 Python tests, including the actual Lua session's
map gate, arrival acknowledgement, host authority, reconnect state, and host
changes during loading. Native UMG appearance and a two-PC map transition still
need in-game acceptance.

Download **RoweMod-0.5.3.zip**, extract, close the game and companion, then run
**install.cmd**. Existing installations can also auto-update after closing.
