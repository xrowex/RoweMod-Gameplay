# RoweMod 0.5.6

Multiplayer now shows a live player list with host/you badges, each player's park and local avatar status. It distinguishes connecting, waiting for poses, map loading/mismatch, interrupted movement and avatar failures. The menu also shows the installed version.

**Copy Diagnostics** gathers transport counters and per-player pose/avatar status into a report for support. It uses player aliases instead of account IDs, names or the session code, and never uploads anything. If the clipboard is unavailable, the report remains in `diagnostics-copy.txt` under `%TEMP%\RoweModMP\Steam`. The Steam companion must be running.

Two visibility-related safeguards are included: incomplete companion status reads no longer clear the host role/avatars, and a Lua render error for one remote avatar no longer stops every other avatar in that render pass. Neither establishes the exact cause of the previously reported host-visibility failure.

Validation: 51 Python tests and 18 Lua suites, covering player rows, host badges, diagnostic redaction/fallback, stale diagnostics, host-role retention on partial reads, explicit leave cleanup and isolated renderer failures. Automated checks use mocked engine objects; native appearance and the reported four-PC session still need live acceptance.

Extract **RoweMod-0.5.6.zip** and run **install.cmd**, or let the automatic updater finish with Rollout and RoweMod Online closed. Settings are preserved.
